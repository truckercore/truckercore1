# Security Training Program

Quarterly Secure Coding Labs
- Focus areas rotate: AuthZ/RLS, secret handling, SSRF/IDOR, injection and sanitization, logging/redaction.
- Format: 1–2 hour hands-on labs with code exercises and review checklists.
- Attendance: all engineers; track completion in HRIS/LMS.

Biannual Incident Drills (Red/Blue)
- Two per year; include timed injects.
- Roles rotate: IC, Comms, Security, Ops.
- Scorecard: detection (MTTD), response (MTTR), comms latency, correctness of decisions.

Onboarding Security Checklist (New Engineers)
- Review SECURITY.md, SECURITY_PROGRAM.md, THREAT_MODEL.md.
- Complete secure coding intro lab and read docs/SECRETS.md, docs/LOGGING.md.
- Set up pre-commit hooks and secret scanning.
- Read runbooks in /runbooks and alerting docs in /alerts.
