# Incident Response Policy (Skeleton)

Purpose: Define roles, severities, triage steps, containment, and recovery.

Severities: P0, P1, P2, P3 with examples.

Controls:
- Detection via alerts/logs; triage checklist
- Containment (disable keys, rotate secrets, block IPs, isolate systems)
- Forensics and evidence preservation
- Communication cadence; regulator notifications when applicable
- Recovery steps aligned to BCDR; validation tests
- Post-incident RCA within 5 business days; actions with owners/dates

Evidence: incident tickets, timelines, RCA docs, action item tracking.
