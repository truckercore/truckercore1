# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by:

1. DO NOT open a public issue
2. Email security@your-domain.com with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We aim to respond within 48 hours and provide a fix within 7 days for critical issues.

## Security Update Process

- Daily: Automated security audits via GitHub Actions
- Weekly: Dependabot security patches automatically merged
- Monthly: Manual security review of all dependencies
- Quarterly: Complete dependency audit and update cycle

## Best Practices

- All dependencies are audited before merging
- Critical vulnerabilities trigger immediate notifications
- Security patches are prioritized over feature development
