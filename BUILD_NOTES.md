   - gradlew.bat tasks
   This should download wrapper/AGP/Kotlin and show tasks with no prompts.

Linux Desktop Build Setup

1) Install Linux build dependencies (Ubuntu/Debian):
   sudo apt-get update
   sudo apt-get install -y clang cmake git ninja-build pkg-config libgtk-3-dev liblzma-dev libstdc++-12-dev
   # For system tray support used by tray_manager:
   sudo apt-get install -y libappindicator3-dev

   Note: For other distros use the equivalent packages via dnf, pacman, zypper, etc.

2) Verify Flutter toolchain:
   flutter doctor
   # Ensure Linux toolchain shows as installed and ready.

3) Run the desktop app (Linux):
   flutter run -d linux -t lib/main_desktop.dart

4) Build a release bundle:
   flutter build linux -t lib/main_desktop.dart
   # Output: build/linux/x64/release/bundle

5) Notes on platform features:
   - System Tray: Requires libappindicator3-dev at build time. No additional code changes are required.
   - Global Hotkeys: Provided by hotkey_manager. On some desktop environments, a permissions prompt (xdg-desktop-portal) may appear on first use.
   - Window Frame: The Linux runner registers the GTK window with bitsdojo_window for custom frame integration.
