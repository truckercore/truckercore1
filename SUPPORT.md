# Support

If you need help using this project, please use the following channels:

- Issues: open a GitHub issue with label `support` for non-security problems.
- Security: DO NOT open a public issue. See SECURITY.md for reporting instructions.
- Email (ops/on-call): ops@example.com
- Slack: #truckercore-support (internal)

Response targets (pilot):
- Business hours: < 4 hours for P1/SEV-1, next business day for others.
- Off-hours: on-call best-effort; page via alerting pipeline if critical.

Useful links:
- On-call Runbook: runbooks/ONCALL_RUNBOOK.md
- Ops Dashboard: /admin/ops
- Health Probe: supabase/functions/healthz
