# Post-Incident Review (PIR) Checklist — Webhooks

- [ ] Incident summary and timeline
- [ ] Impacted endpoints/orgs/providers
- [ ] Root cause and contributing factors
- [ ] Detection: which alerts fired; MTTD
- [ ] Response: actions taken; MTTR
- [ ] Monitoring/Alerting retrospective (see POSTMORTEM_TEMPLATE.md section)
- [ ] Dashboard adequacy: gaps and improvements (dashboards/webhooks_overview.json)
- [ ] Provider communication outcomes (docs/providers/COMMUNICATION_PROCESS.md)
- [ ] Rotation/key provenance analysis (secret_version/key_id)
- [ ] Replay and invalid rate analysis; abuse throttling behavior
- [ ] Action items with owners and due dates
- [ ] Follow-up validation: red-team automation and chaos drills scheduled
